# Phase 1 实施与验收

## 源内容检查

- 来源：2027江苏高考数学基础题SOP宝典_超详细版.docx。
- 100 个 SOP、24 个章节、3751 个正文段落、503 个表格、0 个 OMML。
- 正式内容依据 Heading1 章节、Heading2 SOP、Heading3 小节切分；无标题样式的目录条目不重复导入。
- `source-blocks.json` 保存包括前言、总目录与补充内容在内的所有 4254 个块。单个 SOP 另存文件，不在 React 中硬编码。
- 保留原文 Unicode 公式。未来 OMML / 图形导入会保留原 XML 并写警告，不静默删除。
- 文档没有为每一条独立提供术语翻译模块，不虚构；保留现有解释。逐步提示使用原文固定 SOP，完整例题答案原样保留。

## 交付顺序

1. 导入器、内容模型、报告与解析回归测试。
2. 六科主页、数学搜索/章节/频次/白话判断、SOP 阅读和导航。
3. IndexedDB 自动保存、收藏、笔记、学习状态与最近浏览。
4. 错题录入、多图裁剪与原图、关联、筛选、重做和老毛病统计。
5. Supabase Auth/Storage/RLS/同步迁移，管理员内容管理。
6. PWA、备份、响应式/离线 E2E、README 与 Git 提交。

用户确认先交付本地模式与 Supabase 接入配置。未连接真实云端时不宣称跨设备已验收。

## 同步策略

账号与本机模式按 scope 分区；登录不自动迁移本机数据。复制到账号由用户显式触发，源数据保留。
每次编辑先写 IndexedDB，再排队上传；图片先于引用其 ID 的记录上传。在线、恢复网络和 30 秒定时同步。
每条记录有 revision 和最后已同步 revision。数据库事务检查基线，遇到并发修改保留独立副本，不以设备时钟覆盖另一版。
上传成功后只确认对应 revision，上传期间的新编辑继续保持 dirty。下行内容不能覆盖 dirty 本机记录。
后台关闭时不承诺自动同步；再次打开应用后恢复队列。完整后台同步属于 Phase 2。

## 阶段边界

不开发知识卡流、XP 等级、章节舞台、AI 推理服务或其他五科虚构内容。主题、能力计数和重做正反馈不引入刷分。
HEIC 转换依赖浏览器解码库，异常会显示错误，不丢弃原文件；需用实际手机 HEIC 另行兼容性验收。
管理员编辑后云端版本优先；静态离线内容版本应通过内容导出重新部署。正式上线前需配置真实 Supabase 并运行隔离测试。
